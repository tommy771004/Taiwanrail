# 03 — 落地頁班次數改為 ServiceDay 正確

**What to build:** 落地頁上的班次數不再灌水。目前頁面聲明「每日約 43 班」，但產生邏輯完全不讀 `ServiceDay`，把整週服務模式中所有服務該 OD 的班次都算成「每日」—— 只在週末加開的班次也被計入。使用者因此以為某些班次每天都有。改為分別呈現平日與假日的班次數。

本票同時包含一個 prefactor：時刻表掃描目前在同一個迴圈裡已經取得每一班的出發、抵達與車種，卻在算完聚合統計後全部丟棄。改成回傳實際比對到的班次清單、聚合統計由清單導出 —— 這是票據 04 的地基（「make the change easy, then make the easy change」）。

**Blocked by:** None — can start immediately（與票價工作完全無關，可與票據 01 並行）

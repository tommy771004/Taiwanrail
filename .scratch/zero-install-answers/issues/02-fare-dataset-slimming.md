# 02 — 票價資料集去重瘦身

**What to build:** 台鐵搜尋的首次載入速度提升一倍。使用者每做一次台鐵搜尋就要下載一個起站票價檔，目前約 2.6 MB，其中整整一半是環島反向那筆永遠用不到的資料。資料刷新流程在按起站切檔時套用票據 01 的同一個消歧義模組，並把現有的 240 個起站檔就地重新產生，讓效益立刻到使用者手上，而不必等下一次排程刷新。

**Blocked by:** 01 — 台鐵票價方向消歧義（需要它建立的共用模組）

**Status:** ready-for-agent

- [x] 資料刷新流程在按起站切檔時套用票據 01 的同一個模組（不重複實作規則）
- [x] 現有 240 個起站檔就地重新產生，**不需要 TDX 憑證**（以既有 committed 資料處理）
- [x] **可斷言的不變式**：每個（目的地站, 車種）組合在檔案中僅存一筆，且該筆的行駛距離為原始候選中的最小值
- [x] 體積下降符合預期。以下為 2026-07-30 的**觀測值，供人工核對規模，不得寫成測試常數**（實際比例取決於 TDX 當次回傳有多少單方向 OD）：單一起站檔約 2.6 MB → 約 1.3 MB；票價目錄約 517 MB → 約 259 MB；抽樣檔紀錄數為原本的 50%

- [x] 既有的資料完整性測試（原子替換行為）仍然通過
